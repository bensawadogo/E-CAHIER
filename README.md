# Ecahier

Ecahier — Application moderne de gestion de caisse et de cahier de boutique pour le Burkina Faso.

Interface épurée, offline-first, facile à utiliser.

## Fonctionnalités

- Gestion des clients
- Crédits et remboursements
- Paiements (espèces, mobile money, virement)
- Synchronisation hors ligne
- Tableau de bord en temps réel
